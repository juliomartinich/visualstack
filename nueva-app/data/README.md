# Datos de la Nueva Aplicación

Coloca en esta carpeta tus nuevos archivos JSON con los datos específicos para esta simulación:

1. `Pedidos.json` - Datos de los pedidos diarios.
2. `Tickets.json` - Datos de los tickets/despachos reales.
3. `plantas.json` - Configuración de plantas y bocas.

Asegúrate de que tengan la misma estructura que los de la aplicación principal para que los algoritmos de simulación funcionen correctamente.
